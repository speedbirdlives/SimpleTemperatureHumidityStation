# SimpleTemperatureHumidityStation
Simple temperature and humidity station using basic electronic components.

# Components used: 
Arduino NANO, DHT-11 Temperature and Humidity Sensor, LCD with I2C module, Jumper wires and Single-strand wires.

# Software: 
Arduino IDE

I have included a picture of the setup. Do check it out.

# Basic Logic: 
Read temperature in both degree celsius and fahrenheit from the DHT-11 temperature and humidity sensor. Display readings for 5 seconds and clear the display. Delay for 1 second, take the readings again. This process repeats.
